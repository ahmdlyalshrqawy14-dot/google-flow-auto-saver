# Google Flow Auto Saver Pro (v2.0 Pro) 🚀

إضافة احترافية متكاملة لمتصفحات Google Chrome و Microsoft Edge لأتمتة إرسال البرومبتات (Prompts) غير المحدودة، وتوليد الصور واستخراجها بجودة عالية، وتسميتها تلقائياً حسب الطلب وضغطها في ملفات ZIP.

---

## 🌟 المميزات الاحترافية في الاصدار Pro

### 🤖 1. إدارة البوتات والقوالب الاحترافية (Bot Profiles)
- إنشاء وحفظ عدد غير محدود من البوتات والقوالب الجاهزة للبرومبتات.
- التنقل السريع بين القوالب واسترجاعها بضغطة زر.
- التعديل والحذف والحفظ التلقائي في ذاكرة المتصفح المحلية (`chrome.storage.local`).

### 📂 2. التعامل مع الملفات المتقدمة (Batch Import / Export)
- استيراد وتصدير قائمة البرومبتات بسهولة بصيغ **TXT** أو **JSON** أو **CSV**.
- دعم إدخال عدد غير محدود من البرومبتات (100+ برومبت في المرة الواحدة).

### 📊 3. المتابعة المباشرة والتحكم الكامل (Live Monitor & Controls)
- **شريط تقدم متقدم:** يعرض نسبة التوليد والمكتمل والفاشل والوقت المنقضي بدقة.
- **التحكم المباشر:** زران للإيقاف المؤقت (Pause) والاستئناف (Resume) والإيقاف الكلي (Stop) في أي وقت دون ضياع التقدم.
- **سجل مباشر (Live Log Table):** جدول يعرض كل عملية مع اسمها وحالتها ووقت تنفيذها.

### ⚙️ 4. إعدادات الأمان والتخصيص المتقدمة
- **تفاوت المهلة العشوائية (Random Delay Variance):** تفادي الحظر وأتمتة التوليد بفاصل زمني طبيعي (مثال: 5 ثوانٍ + تفاوت عشوائي ±2 ثوانٍ).
- **إعادة المحاولة التلقائية (Auto-Retry):** إعادة محاولة التوليد عند تجاوز الوقت المحدد أو فشل الاستجابة.
- **تسمية الصور حسب الطلب (Custom Naming):**
  - الرقم فقط (`1.png`).
  - الرقم + بداية البرومبت (`1_cat_in_space.png`).
  - الرقم + التاريخ والوقت (`1_2025-02-28-12-00.png`).
- **التنزيل والإشعارات:** تنزيل تلقائي لملف ZIP عند النهاية وإرسال إشعارات المنظومة.

## 🛠️ طريقة التثبيت على المتصفح

1. قم بتنزيل أو استنساخ المستودع على جهازك.
2. افتح متصفح **Chrome** أو **Edge** وانتقل إلى صفحة الإضافات:
   - في Chrome: `chrome://extensions`
   - في Edge: `edge://extensions`
3. قم بتفعيل **وضع المطور (Developer Mode)** في الأعلى.
4. اضغط على **تحميل إضافة غير محزومة (Load Unpacked)** واختر مجلد المشروع.

---

## 📖 دليل الاستخدام

1. افتح صفحة **Google Flow** في التبويب النشط.
2. انقر على أيقونة الإضافة في شريط المتصفح.
3. **تبويب البرومبتات والبوتات:**
   - اختر بوت مخزناً أو أنشئ بوت جديد.
   - اكتب أو استورد البرومبتات (افصل بسطر فارغ بين كل برومبت).
   - اضغط **🚀 بدء التوليد الأوتوماتيكي**.
4. **تبويب المتابعة:**
   - تابع تقدم التوليد وسجل العمليات لحظة بلحظة.
   - استخدم زر **⏸️ إيقاف مؤقت** أو **▶️ استئناف** حسب الحاجة.
5. **تبويب الإعدادات:**
   - اضبط المهلة الزمنية، التفاوت العشوائي، صيغة التسمية، وعدد محاولات الإعادة.
